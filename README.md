NOME:
Web Project Coffeeshop (web_project_coffeeshop)

DESCRIÇÃO:
'Site criado para fins de aprendizado, site simula uma cafeteria ocupada na qual você precisa ajudar a construir os Blocos (Page, Header, Body etc.) necessários para o funcionamento total do site, como uma seção exclusiva de "Boas-vindas", uma seção de "Vídeos", uma para você preencher seu Cadastro/Dados, e por fim o Rodapé, necessário para demais informações referentes à Cafeteria.'

ATUALIZAÇÕES:
Foi implementado neste site diversas funcionalidades novas (para o úsuario, eu) tais como Metodologia BEM, @import, pseudo-classes, iframes, entre diversas ferramentas disponíveis para o uso. Até o momento, o site se mantém em pé em ótimo estado, não apresenta erros de funcionamento, não apresenta erros gramáticais entre outros erros ou divergências, a manutenção do site se mantém relativamente nova apenas com poucas semanas de criação.
